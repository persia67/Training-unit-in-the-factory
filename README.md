# سامانه مدیریت آموزش پرو (Train Pro - LMS)

«سامانه آموزش پرو» یک سیستم دانش‌بنیان و جامع برای مدیریت، ثبت و تحلیل برنامه‌های آموزشی و ارتقای مهارت پرسنل در صنایع سنگین (با تمرکز بر صنعت فولاد) است. این سامانه با تلفیق تکنولوژی‌های نوین وب، معماری چندسکویی (سه‌گانه) و هوش مصنوعی مولد شرکت گوگل (Gemini)، فرآیند ثبت پرونده‌های آموزشی، محاسبات هزینه‌ای فصلی و تولید محتوای آموزشی را هوشمندسازی کرده است.

---

## 🚀 ویژگی‌های کلیدی (بر اساس ارزش کاربردی و نوآوری)

### ۱. مشاور فرمولاسیون و استودیوی هوشمند محتوا (AI-Powered Content Studio)
*   **تولید خودکار محتوای آموزشی:** با استفاده از مدل پیشرفته `gemini-2.5-flash` پرسنل مسئول آموزش می‌توانند تنها با وارد کردن عنوان و هدف دوره، محتوای متنی غنی (جزوات آموزشی)، سناریوی ویدیویی و ساختار اسلایدهای ارائه‌ی پاورپوینت (PowerPoint Outlines) را به صورت کاملاً فارسی دریافت کنند.
*   **تحلیل هوش تجاری (BI Dashboard Analysis):** قابلیت پایش خودکار نمودارهای مدیریتی و ارائه تحلیل آماری و پیشنهادهای کاربردی در قالب خلاصه‌های استراتژیک چندخطی منطبق با پیشرفت کارخانه.
*   **دستیار صوتی و چت تعاملی:** رابط کاربری گفتگوی متنی و صوتی هوشمند جهت تصمیم‌گیری در خصوص دوره‌ها و استانداردهای صنعت فولاد.

### ۲. موتور گواهی‌نامه‌ساز هوشمند (Custom Certificate Engine)
*   **صدور دیجیتال پرونده‌محور:** صدور آنی مدرک پایان‌دوره برای هر پرسنل با امکان انتخاب کیفیت خروجی رندر شده (1K, 2K, 4K) به همراه پیاده‌سازی امضاهای پویای مدیران ارشد (مدیرعامل و مسئول آموزش) و درج خودکار لوگوی اختصاصی بارگذاری‌شده شرکت.

### ۳. ماژول گزارش‌دهی چندبعدی و اکسل‌محور (Enterprise Reporting & Formatting)
*   **تحلیل بر اساس الگوی اکسل (Custom Template Validation):** امکان آپلود قالب سفارشی اکسل کارخانجات بزرگ جهت همگام‌سازی ستون‌ها و تطبیق ساختار گزارش‌دهی داخلی بدون نیاز به کدنویسی مجدد.
*   **محاسبه تجمیعی فصلی و سالیانه:** ثبت عملکرد، نفر-ساعت آموزش، هزینه‌های سرانه پرسنلی برای دپارتمان‌ها و چارت‌های سازمانی مختلف به فرمت تفکیکی و ارائه نتایج آماری سالیانه.
*   **سیستم ایمپورت هوشمند:** آپلود دسته‌جمعی پرسنل و تاریخچه‌ی دوره‌های گذرانده شده کارکنان از طریق فایل‌های اکسل به کمک کتابخانه `XLSX`.

### ۴. سیستم دسترسی چندسطحی (Role-Based Access)
*   **مدیریت هویت سازمانی:** تفکیک تجارب کاربری بین سطوح دسترسی توسعه‌دهنده (Developer)، مدیر کارخانه (Factory Manager) و مسئول آموزش (Training Manager) جهت پیشگیری از خطای انسانی و تغییر ناخواسته تنظیمات کلیدی.

### ۵. معماری چندسکویی سه‌گانه (Cross-Platform Architecture)
*   **برنامه وب (Vite SPA):** اجرای سبک و واکنش‌گرا در مرورگر.
*   **نسخه دسکتاپ سبک با تائوری (Tauri Desktop):** برخورداری از ایمنی بالا و حجم باینری بهینه با به کارگیری هسته قدرتمند Rust.
*   **نسخه دسکتاپ همه‌منظوره با الکترون (Electron):** سازگاری عمیق با سیستم‌عامل‌های ویندوز و لینوکسِ محیط‌های صنعتی.

## 🛠️ تکنولوژی‌های مورد استفاده

*   **فریم‌ورک اصلی:** React 19 به همراه TypeScript (مدیریت امن ساختارهای داده و رابط کاربری کامپوننت‌محور)
*   **موتور فرانت‌اند:** Vite (برای پیش‌نمایش بهینه و سرعت حداکثری توسعه)
*   **هواشناسی و استایل دهی:** Tailwind CSS (طراحی کاملاً ایرانی با فونت زیبای وزیرمتن، کاملاً راست‌چین و واکنش‌گرا برای موبایل و تبلت)
*   **مدل هوش مصنوعی:** `@google/genai` (نصب رسمی نسخه جدید SDK برای ارتباط پایدار با API های مدل `gemini-2.5-flash`)
*   **ابزارها و کتابخانه‌های کمکی:**
    *   `recharts`: ترسیم نمودارهای مدیریتی پیشرفته نظیر روند آموزش ماهانه، توزیع واحدی و عملکرد به بودجه.
    *   `xlsx`: پردازش و پارس فایل‌های فایل‌های اکسل در بخش دپارتمانی و ثبت سوابق.
    *   `lucide-react`: استفاده از آیکون‌های وکتور بسیار تمیز و هماهنگ.

## 📁 ساختار پوشه‌های پروژه

```text
├── App.tsx                  # کامپوننت اصلی و هماهنگ‌کننده کل بخش‌های لایوت
├── constants.ts             # ثابت‌های سیستم، دیتای اولیه کارخانه و ترجمه‌ها (fa/en)
├── types.ts                 # تعاریف تایپ‌ها، اینترفیس‌ها و انوم‌های TypeScript
├── services/
│   └── geminiService.ts     # سرویس مجزا برای هندل تسک‌های گوناگون Gemini API
├── electron/
│   ├── main.js              # ساختار اصلی فرآیند الکترون جهت اجرای دسکتاپ
│   └── preload.js           # پل ارتباطی امن الکترون برای رندر فرانت‌اند
├── src-tauri/               # کدهای مربوط به کامپایل فریم‌ورک Rust Tauri
├── package.json             # پکیج‌ها، وابستگی‌ها و اسکریپت‌های سیستمی
└── tsconfig.json            # پیکربندی کامپایلر تایپ‌اسکریپت
```

## ⚡ راهنمای استفاده سریع (Quick Start)

### پیش‌نیازها
مطمئن شوید که [Node.js](https://nodejs.org/) و یک مدیر بسته مانند `npm` روی سیستم شما نصب باشد.

### ۱. نصب وابستگی‌ها
پوشه پروژه را در ترمینال باز کنید و دستور زیر را اجرا کنید:
```bash
npm install
```

### ۲. اجرای نسخه وب در حالت توسعه (Web Dev Mode)
برای اجرای سرور توسعه وب‌سایت با پورت محلی:
```bash
npm run dev
```

### ۳. بیلد و خروجی نسخه وب (Production Build)
جهت ایجاد نسخه فشرده و بهینه‌سازی شده در دایرکتوری `dist`:
```bash
npm run build
```

### ۴. اجرای نسخه دسکتاپ الکترون (Desktop dev)
جهت اجرای نرم‌افزار در قالب اپلیکیشن دسکتاپ بومی:
```bash
npm run start
```

### ۵. خروجی گرفتن نهایی الکترون (Desktop Package)
برای بسته‌بندی اپلیکیشن در فرمت‌های قابل‌ نصب سیستم‌عامل (مانند `.exe` یا `.deb`):
```bash
npm run dist
```
